EMAX ORDER PAGE SERVER-SIDE PAGINATION FIX

WHAT CHANGED
- The Order page now asks Supabase for only 25 matching orders per page.
- Search, branch filter, phase filter, completed filter and sorting run in Supabase.
- KPI counts are loaded using lightweight count queries.
- Bulk actions load only the relevant orders when the bulk window is opened.
- Reports load full report data only when you click a report download button.
- Saving one order updates only that order row.
- Deleting one order deletes only that row.

FILES CHANGED
- src/OrderTab.jsx
- src/storage/orders.js

IMPORTANT
Your Supabase public.orders table must already exist. The SQL file is:
- supabase/orders-migration.sql

INSTALL
1. Back up and push your current project first.
2. Extract this ZIP.
3. Copy all files inside this folder into your existing project folder.
4. Select "Replace files in destination".
5. Keep your existing .env file.
6. In Command Prompt inside the project folder, run:
   npm install
   npm run dev
7. Test the Order page before pushing.
8. Then commit and push using GitHub Desktop.

NOTE
The first Order page request now returns at most 25 order JSON records instead of every order.
